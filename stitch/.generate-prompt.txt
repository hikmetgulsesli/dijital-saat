# dijital-saat — Urun Gereksinim Dokumant

## 1. Genel Bakis
- **Proje Adi:** dijital-saat
- **Platform:** Web (SPA)
- **Tipoloji:** Minimal utility uygulamasi
- **Ozet:** Tek sayfalik dijital saat uygulamasi. Buyuk fontla saat:dakika:saniye gosterimi. Tarih gosterimi. Koyu tema. Minimal tasarim.
- **Hedef Kullanici:** Herkes

- **Platform:** Web (mobil uyumlu responsive tasarim)
- **Tarayici Destegi:** Chrome, Firefox, Safari, Edge
