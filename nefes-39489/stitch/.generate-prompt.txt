# Nefes-39489: Nefes Egzersizi Uygulaması — PRD

## 1. Proje Özeti

**Proje Adı:** Nefes-39489  
**Platform:** Web (React 18 + Vite + Tailwind CSS)  
**Proje Türü:** Meditasyon / Wellness SPA  
**Özet:** Kullanıcıların farklı nefes tekniklerini (4-4-4, 4-7-8) uygulayarak gevşeme ve odaklanma sağlayabilecekleri animasyonlu, sesli bir nefes egzersizi uygulaması.  

**Hedef Kitle:** 
- Stres yönetimi ve gevşeme arayan bireyler
- Meditasyon新手
- Uyku kalitesini artırmak isteyenler
- Odaklanma sorunu yaşayan profesyoneller

---

## 2. Fonksiyonel Gereksinimler

### 2.1 Nefes Teknikleri

| Teknik | Açıklama | Döngü |
|--------|----------|-------|
| **4-4-4 (Kutu Nefesi)** | Eşit sürede nefes al → tut → ver | 4sn × 3 = 12sn |
| **4-7-8 (Rahatlatıcı Nefes)** | 4sn nefes al → 7sn tut → 8sn ver | 4+7+8 = 19sn |

### 2.2 Ana Ekran Bileşenleri

1. **Animasyonlu Çember**
   - Genişleyen/küçülen dairesel animasyon
   - Nefes_al = ölçek 1.0 → 1.8 (büyüme)
   - Nefes_tut = ölçek 1.8 sabit
   - Nefes_ver = ölçek 1.8 → 1.0 (küçülme)
   - Animasyon süresi CSS transitions ile kesin kontrol

2. **Teknik Seçici**
   - İki seçenek: "4-4-4 Kutu Nefesi" ve "4-7-8 Rahatlatıcı Nefes"
   - Aktif seçim görsel olarak vurgulanır (border + glow)
   - Seçim değiştiğinde animasyon ritmi güncellenir

3. **Zamanlayıcı (Timer)**
   - Kalan süreyi dakika:saniye formatında gösterir (MM:SS)
   - Büyük, okunaklı font
   - Geri sayım başladığında görünür

4. **Seans Süresi Seçici**
   - Üç seçenek: 3 dakika, 5 dakika, 10 dakika
   - Düğme grubu (button group) olarak gösterilir
   - Varsayılan: 5 dakika

5. **Ses Efektleri**
   - Nefes_al sesi: Yumuşak, kısa bir tones (~200ms)
   - Nefes_ver sesi: Hafif, uzun bir tones (~300ms)
   - Ses açık/kapalı toggle butonu
   - Web Audio API ile oynatılır (base64 inline veya harici .mp3/.wav)

6. **Kontrol Butonları**
   - **Başlat:** Seansı başlatır, buton "Duraklat"a döner
   - **Duraklat:** Seansı geçici olarak durdurur, "Devam Et"e döner
   - **Sıfırla:** Seansı baştan başlatır
   - Butonlar arasında net görsel hiyerarşi (Başlat > Duraklat > Sıfırla)

7. **İlerleme Göstergesi**
   - Tamamlanan nefes döngüsü sayısı
   - "X. döngü" formatında
   - Toplam hedef döngü hesaplaması: toplam_süre / döngü_süresi

### 2.3 Seans Tamamlandığında

- Animasyon durur, çember nötr pozisyona döner
- "Seans Tamamlandı" mesajı gösterilir
- Sesli bildirim (opsiyonel)
- "Tekrar Başlat" ve "Ayarlara Dön" butonları

### 2.4 Ayarlar Paneli (Overlay/Modal)

- **Ses efekti:** Açık / Kapalı
- **Teknik varsayılanı:** 4-4-4 veya 4-7-8
- **Seans süresi varsayılanı:** 3/5/10 dakika
- Ayarlar localStorage'da saklanır

## 6. Oyun Durumu (State Machine)

Uygulama aşağıdaki durumlardan birinde olacaktır:

| Durum | Açıklama |
|-------|----------|
| `IDLE` | Başlangıç, ayarlar yapılabilir, başlatmaya hazır |
| `RUNNING` | Seans aktif, animasyon çalışıyor |
| `PAUSED` | Seans duraklatıldı |
| `COMPLETE` | Seans tamamlandı |

**Geçişler:**
- IDLE → RUNNING (Başlat)
- RUNNING → PAUSED (Duraklat)
- PAUSED → RUNNING (Devam Et)
- PAUSED → IDLE (Sıfırla)
- RUNNING → COMPLETE (Süre dolduğunda)
- COMPLETE → IDLE (Ayarlara Dön veya Tekrar Başlat)
