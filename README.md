# sayac-30261

Basit sayaç uygulaması - React 18, Vite, TypeScript, Tailwind CSS

## Özellikler

- Sayacı arttırma/azaltma
- Hızlı ekleme butonları (+5, +10)
- localStorage ile veri saklama
- Son 5 işlem geçmişi
- Açık/koyu tema desteği
- Mobil uyumlu tasarım
- WCAG AA erişilebilirlik

## Teknolojiler

- React 18
- TypeScript
- Vite
- Tailwind CSS 3
- Material Symbols

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
